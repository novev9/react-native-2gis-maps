# react-native-dgis-maps

React Native Fabric binding for 2GIS Mobile SDK (New Architecture)

## Installation


```sh
npm install react-native-dgis-maps
```


## Usage


```js
import { DgisMapsView } from "react-native-dgis-maps";

// ...

<DgisMapsView color="tomato" />
```
